# Kako pokrenuti novu verziju

Ovaj ZIP je potpuna, pojednostavljena verzija portfolija. Najlakše je da njime zamijeniš stari lokalni folder.

1. U Terminalu u kojem radi stara verzija pritisni `Control + C`.
2. Raspakuj novi ZIP.
3. Stari folder `ibrahim-portfolio-vercel` preimenuj kao backup ili ga zamijeni novim raspakovanim folderom.
4. Otvori Terminal u novom folderu.
5. Instaliraj pakete:

   ```bash
   npm install
   ```

6. Pokreni stranicu:

   ```bash
   npm run dev
   ```

7. Otvori adresu koju Terminal prikaže. Obično je `http://localhost:3000`; ako je port zauzet, Next.js će prikazati npr. `http://localhost:3001`.
