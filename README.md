# Ibrahim Causevic — Portfolio

Interactive personal portfolio built with Next.js. It includes a macOS-inspired tabbed interface, selected projects, background, experience and contact details.

## Local development

```bash
npm install
npm run dev
```

Open the local address shown in Terminal, usually `http://localhost:3000`.

## Production check

```bash
npm run lint
npm run build
```

The project can be connected to its own GitHub repository and deployed as a separate Vercel project.
